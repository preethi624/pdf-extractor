# PDF Extractor Web Application

A simple web application that allows users to **upload PDF files**, view them, select specific pages, and **create a new PDF** containing only the selected pages.

---

##  Features

- Upload PDF files through the browser.
- Preview uploaded PDFs.
- Select pages to extract.
- Generate a new PDF with only the selected pages.
- Download the newly created PDF.

---

##  Technologies Used

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
